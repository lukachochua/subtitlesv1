# Georgian Transcription Quality

This is the source of truth for Georgian ASR quality experiments. The product metric is human correction effort per finished audio minute; WER and CER are supporting diagnostics.

## Production control

- Model: `nvidia/stt_ka_fastconformer_hybrid_large_pc`
- Decoder: the model's default RNNT decoder
- Invocation: `model.transcribe([str(audio_path)], batch_size=1, return_hypotheses=True, timestamps=True)`
- Audio: mono, 16 kHz, signed 16-bit PCM WAV produced by `ExtractVideoProjectAudio`
- Raw result: preserved as `transcription.nemo-fastconformer.raw.json`
- Status on 2026-08-31: confirmed in the checked-in production path; no beam or CTC override is active.

Do not change this control while evaluating a different variable.

## Evaluation workflow

Copy `docs/transcription-evaluation.manifest.example.json` to a private working location. Media, verified references, raw model outputs, result JSON, and credentials must not be committed.

For every clip:

1. Create or extract a mono 16 kHz WAV. Keep a clean microphone category and real-world/YouTube categories separate.
2. Manually transcribe the speech verbatim in Georgian, or approve another human's transcript. Do not improve grammar or use NeMo output as ground truth.
3. Run the stable NeMo script and preserve its raw JSON:

   ```bash
   /absolute/path/to/georgian-captioner-nemo/bin/python transcribe_nemo.py /private/clip.wav /private/clip.nemo.json
   ```

4. Add `audio`, `reference`, `category`, and `nemo_result` to the manifest. Paths may be absolute or relative to the manifest.
5. Optionally add positive `audio_duration_seconds` and `manual_correction_seconds`. The evaluator then reports correction seconds per audio minute.
6. Evaluate without calling NeMo or an external API:

   ```bash
   php artisan transcription:evaluate /private/manifest.json --output=/private/results.json
   ```

The command writes per-clip and micro-averaged WER, CER, substitutions, insertions, deletions, and normalized text. It Unicode-normalizes, replaces punctuation with boundaries, and normalizes whitespace. Georgian suffixes, morphology, and word forms remain unchanged. CER is measured on the same punctuation-free normalized text.

Start with 10–20 short, human-verified clips. Give each dataset revision a new `dataset_version`. Never train on this evaluation set.

## Conservative Georgian post-editor experiment

This is experimental and is not connected to normal caption generation. `ApplyTranscriptionCorrections` validates zero-based, one-token replacement operations and creates new timed words while retaining raw words and exact start/end timestamps.

Use this system instruction for the first provider experiment:

```text
You are a conservative Georgian ASR post-editor.

The input was generated by automatic speech recognition from spoken Georgian. Preserve the speaker's actual wording. Do not rewrite for style, paraphrase, formalize informal Georgian, introduce facts, invent missing speech, or change plausible proper nouns based only on context.

Correct only errors supported by strong linguistic evidence, such as malformed Georgian morphology, case or suffix errors, agreement errors, and highly probable spelling-like ASR substitutions. When uncertain, make no correction.

Return only structured correction operations. Each operation must replace exactly one existing token with exactly one token and contain word_index, original, replacement, category, and confidence. word_index is zero-based. Do not add, delete, split, merge, or reorder tokens.
```

Expected response shape:

```json
{
    "corrections": [
        {
            "word_index": 14,
            "original": "ნაკრები",
            "replacement": "ნაკრების",
            "category": "morphology",
            "confidence": 0.97
        }
    ]
}
```

Preserve four artifacts separately: raw NeMo JSON, raw timed words, correction operations, and corrected candidate output. Compare raw and corrected candidates on identical clips, reporting WER, CER, fixed errors, and newly introduced errors. Report clean and difficult audio separately.

### MANUAL SETUP REQUIRED

No supported LLM API or credential is configured, and no provider client dependency has been added. Before a live run:

1. Select one currently available Georgian-capable model using its provider's official documentation and confirm reliable structured JSON output.
2. Obtain an account/API key and billing approval from that provider.
3. Obtain approval before adding its PHP SDK or HTTP integration and a provider-specific `.env` variable to this repository.
4. Keep the key only in `.env`; add only an empty variable name to `.env.example`.
5. Run the integration as an explicit experiment against private copies of the evaluation clips; never call it in the automated suite or production caption action.
